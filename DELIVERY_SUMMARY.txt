================================================================================
                       QUICK DEPLOYMENT GUIDE
================================================================================

Step 1: Deploy Smart Contracts (5-10 minutes)
  cd contracts
  export RPC_URL=https://mainnet.base.org
  export PRIVATE_KEY=0x...
  forge script script/Deploy.s.sol --rpc-url $RPC_URL --private-key $PRIVATE_KEY --broadcast

Step 2: Update Frontend Config (1 minute)
  Create frontend/.env.local:
  VITE_CHONK_ADDRESS=0x...
  VITE_STAKING_ADDRESS=0x...
  VITE_POOL_ADDRESS=0x...

Step 3: Deploy Frontend (5 minutes)
  cd frontend
  git add .
  git commit -m "Release v1.0.0"
  git push origin main
  Import to Vercel and set env variables

Step 4: Verify (10 minutes)
  Check contracts on BaseScan
  Test all app features
  Monitor gas usage

Total Time: 30-45 minutes

See DEPLOYMENT.md for detailed instructions.
